# arms.glb

"Low Poly Arms (Rigged)" from OpenGameArt, CC0 (public domain):
https://opengameart.org/content/low-poly-arms-rigged

Converted: mirror applied, split L/R into meshes `ArmL` / `ArmR`, deform bones only,
no materials, no animations. Skinned in game with the grime shader
(`ArmMaterials.skin`); no bitmap texture is used.
